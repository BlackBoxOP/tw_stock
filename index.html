零成本、極速查詢的
台股 1 分 K 線與 Parquet 資料庫

每日盤後由 GitHub Actions 自動增量同步「1 分鐘 K 線」與「日線」三維度資料，並採集 TWSE 官方 OpenAPI 盤中委託成交統計。透過 GitHub Pages / 自訂網域託管，結合 DuckDB HTTP Range 請求，免下載整包資料庫即可完成跨網域極速分析。

維度一 回測最優

個股分檔 (by_ticker)

優先包含 1 分鐘 K 線（無分時者包含日線），單股高頻回測最佳選擇。

/data/by_ticker/{TICKER}.parquet
維度二 選股最優

單日快照 (by_date)

包含當天全市場標的成交價量，適合盤後選股、漲跌排行與快照分析。

/data/by_date/{YYYY-MM-DD}.parquet
維度三 統計最優

年度彙整 (by_year)

單一檔案彙整該年度全市場數據，適合跨年度大盤趨勢與總經週期統計。

/data/by_year/{YYYY}.parquet
官方 OpenAPI 動能最優

TWSE 盤中統計

證交所官方 OpenAPI 每日盤中每 5 秒/5 分委託成交統計與量能熱區。

/data/twse_openapi/mi_5mins/{DATE}.parquet

如何使用 DuckDB 跨網域遠端查詢？

利用 HTTP Range Request 僅下載查詢所需的少量資料區塊，毫秒級完成 SQL 計算：

import duckdb

BASE_URL = "https://stocks.blackboxop.eu.cc/data"

# 1. 查詢台積電 (2330) 最近 5 根 1 分鐘 K 線 (若為日線則查詢 Date)
df_tsmc = duckdb.query(f"""
    SELECT Datetime, Open, High, Low, Close, Volume 
    FROM '{BASE_URL}/by_ticker/2330_TW.parquet' 
    ORDER BY Datetime DESC LIMIT 5
""").df()
print(df_tsmc)

# 2. 查詢 TWSE 官方 OpenAPI 盤中成交爆量時段
df_openapi = duckdb.query(f"""
    SELECT Time_Formatted as Time, IntervalTradeVolume, IntervalTradeValue 
    FROM '{BASE_URL}/twse_openapi/mi_5mins/2026-09-09.parquet' 
    ORDER BY IntervalTradeVolume DESC LIMIT 5
""").df()
print(df_openapi)
