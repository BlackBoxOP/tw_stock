零成本、極速查詢的
三維度台股 Parquet 資料中心

每日盤後由 GitHub Actions 自動增量更新，按「個股、單日、年份」三種維度智能切分。透過 GitHub Pages 託管，結合 DuckDB HTTP Range 請求，免下載整包資料庫即可在毫秒內完成 SQL 跨網域分析。

維度一 個股回測最優

按代號分檔 (by_ticker)

單一檔案包含單一個股所有歷史日線（例如台積電、鴻海等），回測單股無需讀取其他標的。

/data/by_ticker/{TICKER}.parquet
範例：data/by_ticker/2330_TW.parquet
維度二 當日選股最優

按單日分檔 (by_date)

單一檔案包含當天全市場 2,000+ 檔標的成交價量，適合盤後選股、漲跌排行與快照分析。

/data/by_date/{YYYY-MM-DD}.parquet
範例：data/by_date/2026-09-08.parquet
維度三 大盤統計最優

按年份分檔 (by_year)

單一檔案彙整該年度所有標的完整資料，適合跨年總經走勢、市場成交總量宏觀趨勢統計。

/data/by_year/{YYYY}.parquet
範例：data/by_year/2026.parquet

如何使用 DuckDB 跨網域遠端查詢？

無需預先下載檔案，利用 HTTP Range Request 僅讀取 SQL 所需的 Column 與 Row Group

import duckdb

# 透過 GitHub Pages URL 直接連線查詢（也可切換為本地相對路徑）
BASE_URL = "https://blackboxop.github.io/tw_stock/data"

# 1. 個股查詢：只讀取 2330 台積電歷史日線
df_tsmc = duckdb.query(f"""
    SELECT Date, Open, High, Low, Close, Volume 
    FROM '{BASE_URL}/by_ticker/2330_TW.parquet' 
    ORDER BY Date DESC LIMIT 5
""").df()
print(df_tsmc)

# 2. 今日選股：取得成交量前 5 大個股
df_hot = duckdb.query(f"""
    SELECT Ticker, Close, Volume 
    FROM '{BASE_URL}/by_date/2026-09-08.parquet' 
    ORDER BY Volume DESC LIMIT 5
""").df()
print(df_hot)
